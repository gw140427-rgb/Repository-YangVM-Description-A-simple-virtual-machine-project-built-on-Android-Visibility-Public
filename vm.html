실험 메모

메모는 이 브라우저에만 저장됩니다.

정확한 상태: 이 페이지는 CollabVM 스타일의 인터페이스 프로토타입입니다. 자체 QEMU 서버, VM 화면 스트리밍, 키보드·마우스 전달, 다중 사용자 동기화는 아직 구현되지 않았습니다. ‘브라우저 VM 데모 열기’는 공식 v86 사이트를 새 탭에서 열 뿐이며, YangVM과 연결되지는 않습니다.

다음 개발 단계

  1. v86 같은 브라우저 에뮬레이터를 이 프로젝트 안에서 실제로 실행하도록 통합하고 합법적으로 배포된 테스트 이미지를 연결.
  2. 실제 화면과 키보드 입력을 모바일 브라우저에서 검증.
  3. 여러 사용자가 같은 VM을 조작하는 기능이 필요하면 서버·접속 제어·악용 방지 기능을 별도 설계.

현재 구현 완료: UI, 상태 표시, 브라우저 로컬 메모. 실제 VM 연결과 공동 조작은 미완료입니다.
