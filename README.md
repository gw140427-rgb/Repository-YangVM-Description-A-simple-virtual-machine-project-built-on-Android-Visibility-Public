# YangVM

A simple virtual machine project built on Android.

## About

YangVM is an experimental project to explore how a virtual computer works, starting with a simple browser-based PC interface.

## Goals

- Create a simple virtual PC screen
- Simulate a basic startup and boot sequence
- Add an on-screen keyboard
- Explore simple commands and computer concepts

## Getting started

The first version is planned as a lightweight web app using HTML, CSS, and JavaScript. It is a simulation, not a hardware-level virtual machine.

## Project status

Early prototype — features are planned and may not be implemented yet.
